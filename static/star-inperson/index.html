iPad / Safari refresh checklist
  • Safari caps animation at 60 Hz unless Settings → Apps → Safari → Advanced → Feature Flags → "Prefer Page Rendering Updates near 60fps" is turned OFF.
  • Low Power Mode must be off (it caps at 60 Hz).
  • Settings → Accessibility → Motion → "Limit Frame Rate" must be off (caps at 60 Hz).
  • Run from the Home Screen icon (Share → Add to Home Screen) for true fullscreen, landscape only.
